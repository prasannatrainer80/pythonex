

1. Simple K-Means Example — Customer Segmentation

Suppose we have customers with Annual Income and Spending Score. We can group them into 3 customer segments.

Install libraries
pip install numpy pandas matplotlib scikit-learn
Python program
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans

# Sample customer data
data = {
    "Customer": ["A", "B", "C", "D", "E",
                 "F", "G", "H", "I", "J"],
    "AnnualIncome": [20, 22, 25, 28, 30,
                     70, 75, 80, 85, 90],
    "SpendingScore": [80, 85, 75, 78, 82,
                      30, 35, 25, 20, 28]
}

df = pd.DataFrame(data)

# Select features
X = df[["AnnualIncome", "SpendingScore"]]

# Create K-Means model
kmeans = KMeans(n_clusters=2, random_state=42, n_init=10)

# Train model
df["Cluster"] = kmeans.fit_predict(X)

print(df)

# Display cluster centers
print("\nCluster Centers:")
print(kmeans.cluster_centers_)

# Visualization
plt.scatter(
    df["AnnualIncome"],
    df["SpendingScore"],
    c=df["Cluster"]
)

plt.scatter(
    kmeans.cluster_centers_[:, 0],
    kmeans.cluster_centers_[:, 1],
    marker="X",
    s=200
)

plt.xlabel("Annual Income")
plt.ylabel("Spending Score")
plt.title("Customer Segmentation using K-Means")
plt.show()
Output concept

The algorithm groups customers based on similarity:

Customer  AnnualIncome  SpendingScore  Cluster
A         20             80             0
B         22             85             0
C         25             75             0
...
F         70             30             1
G         75             35             1
...
2. K-Means with 3 Clusters

A more interesting example is grouping customers into:

Low income / high spending
Medium income / medium spending
High income / low spending

3. Finding the Best Number of Clusters — Elbow Method

One important question with K-Means is:

How do we decide the value of K?

The Elbow Method is commonly used.

import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans

data = {
    "Income": [
        20, 22, 25, 28,
        40, 42, 45, 48,
        70, 75, 80, 85
    ],

    "Spending": [
        80, 85, 78, 82,
        50, 55, 52, 48,
        20, 25, 22, 28
    ]
}

df = pd.DataFrame(data)

X = df[["Income", "Spending"]]

inertia = []

for k in range(1, 7):

    model = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=10
    )

    model.fit(X)

    inertia.append(model.inertia_)

plt.plot(range(1, 7), inertia, marker="o")

plt.xlabel("Number of Clusters (K)")
plt.ylabel("Inertia")
plt.title("Elbow Method")

plt.show()

The point where the decrease in inertia starts becoming less dramatic is used as an indication of a suitable K.

4. K-Means Using the Iris Dataset

This is a very good Machine Learning classroom example.

from sklearn.datasets import load_iris
from sklearn.cluster import KMeans
import pandas as pd

# Load dataset
iris = load_iris()

# Create DataFrame
df = pd.DataFrame(
    iris.data,
    columns=iris.feature_names
)

print(df.head())

# Select features
X = iris.data

# Create model
model = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

# Perform clustering
df["Cluster"] = model.fit_predict(X)

print("\nClustered Data:")
print(df.head(20))

print("\nCluster Centers:")
print(model.cluster_centers_)

Here K-Means discovers 3 groups from the measurements without using the actual flower species labels.

5. K-Means with Visualization

Using the Iris dataset:

import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.cluster import KMeans

iris = load_iris()

X = iris.data[:, [0, 2]]

model = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

clusters = model.fit_predict(X)

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=clusters
)

plt.scatter(
    model.cluster_centers_[:, 0],
    model.cluster_centers_[:, 1],
    marker="X",
    s=200
)

plt.xlabel("Sepal Length")
plt.ylabel("Petal Length")
plt.title("Iris Clustering using K-Means")

plt.show()
6. K-Means with MySQL Database

Since you're also working with Python + MySQL, K-Means can be combined with a database.

Example table:

    CustomerID INT PRIMARY KEY,

Python:

import pandas as pd
import mysql.connector
from sklearn.cluster import KMeans

# Connect to MySQL
connection = mysql.connector.connect(
    host="localhost",
    user="root",
    password="root",
    database="ml"
)

# Read data
query = """
SELECT CustomerID, Name, Income, SpendingScore
FROM Customer
"""

df = pd.read_sql(query, connection)

# Features
X = df[["Income", "SpendingScore"]]

# K-Means
model = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

df["Cluster"] = model.fit_predict(X)

print(df)

connection.close()
