1. What is Unsupervised Learning?

In unsupervised learning, the dataset does not contain a target/output column. The algorithm tries to discover hidden patterns or groups in the data.

Common techniques:

Technique	Purpose	Python Algorithm
Clustering	Group similar data	K-Means
Hierarchical Clustering	Build a cluster hierarchy	AgglomerativeClustering
Density Clustering	Find dense groups/outliers	DBSCAN
Dimensionality Reduction	Reduce features	PCA
Association Rules	Find item relationships	Apriori
Example 1: K-Means Clustering – Students

Suppose we have students with:

Study Hours
Exam Marks

We want Python to automatically divide students into groups.

import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans

data = {
    "StudyHours": [1, 2, 2, 3, 8, 9, 10, 11],
    "Marks":      [35, 40, 45, 50, 75, 80, 85, 90]
}

df = pd.DataFrame(data)

print(df)

# Create K-Means model
model = KMeans(n_clusters=2, random_state=42, n_init=10)

# Train model
model.fit(df)

# Add cluster number
df["Cluster"] = model.labels_

print(df)

# Plot clusters
plt.scatter(
    df["StudyHours"],
    df["Marks"],
    c=df["Cluster"]
)

plt.xlabel("Study Hours")
plt.ylabel("Marks")
plt.title("Student Clustering")

plt.show()
Expected idea

The algorithm may discover:

Cluster 0 → Students with lower study hours and marks
Cluster 1 → Students with higher study hours and marks

Notice that we didn't tell the algorithm which students are good or weak. It discovered the groups itself.

Example 2: Customer Segmentation

This is one of the most useful real-world applications of clustering.

Suppose a company has:

Annual Income
Spending Score

We can automatically identify customer groups.

import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans

data = {
    "Income": [20, 25, 30, 35, 80, 85, 90, 95, 40, 45],
    "Spending": [20, 25, 30, 35, 80, 85, 90, 95, 60, 65]
}

df = pd.DataFrame(data)

model = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

model.fit(df)

df["Cluster"] = model.labels_

print(df)

plt.scatter(
    df["Income"],
    df["Spending"],
    c=df["Cluster"]
)

plt.xlabel("Annual Income")
plt.ylabel("Spending Score")
plt.title("Customer Segmentation")

plt.show()

Possible interpretation:

Cluster 0 → Low-income customers
Cluster 1 → High-income/high-spending customers
Cluster 2 → Medium-income customers
Example 3: K-Means with the Iris Dataset

The famous Iris dataset is useful for learning clustering.

import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.cluster import KMeans

iris = load_iris()

X = iris.data

model = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

model.fit(X)

clusters = model.labels_

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=clusters
)

plt.xlabel("Sepal Length")
plt.ylabel("Sepal Width")
plt.title("Iris Clustering")

plt.show()

Here we deliberately don't use:

iris.target

because the goal is to perform unsupervised learning.

Example 4: Finding the Best Number of Clusters – Elbow Method

One important question with K-Means is:

How do we decide n_clusters?

The Elbow Method is commonly used.

import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.cluster import KMeans

iris = load_iris()

X = iris.data

inertia = []

for k in range(1, 11):

    model = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=10
    )

    model.fit(X)

    inertia.append(model.inertia_)

plt.plot(range(1, 11), inertia, marker="o")

plt.xlabel("Number of Clusters")
plt.ylabel("Inertia")
plt.title("Elbow Method")

plt.show()

The point where the curve starts to bend significantly is called the elbow.

That value can be a good choice for K.

Example 5: Hierarchical Clustering

Another important clustering algorithm is Agglomerative Clustering.

import pandas as pd
import matplotlib.pyplot as plt

from sklearn.cluster import AgglomerativeClustering

data = {
    "Income": [20, 25, 30, 35, 80, 85, 90, 95],
    "Spending": [20, 25, 30, 35, 80, 85, 90, 95]
}

df = pd.DataFrame(data)

model = AgglomerativeClustering(
    n_clusters=2
)

df["Cluster"] = model.fit_predict(df)

print(df)

plt.scatter(
    df["Income"],
    df["Spending"],
    c=df["Cluster"]
)

plt.xlabel("Income")
plt.ylabel("Spending")

plt.title("Hierarchical Clustering")

plt.show()
Example 6: DBSCAN Clustering

DBSCAN is particularly useful when the clusters aren't simple circular groups and when you want to identify noise/outliers.

import matplotlib.pyplot as plt

from sklearn.datasets import make_moons
from sklearn.cluster import DBSCAN

X, y = make_moons(
    n_samples=300,
    noise=0.05,
    random_state=42
)

model = DBSCAN(
    eps=0.2,
    min_samples=5
)

clusters = model.fit_predict(X)

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=clusters
)

plt.title("DBSCAN Clustering")
plt.xlabel("X")
plt.ylabel("Y")

plt.show()

DBSCAN can identify:

Cluster 0
Cluster 1
Noise → -1

This makes DBSCAN useful for outlier detection as well.

Example 7: PCA – Dimensionality Reduction

PCA is another important unsupervised learning technique.

Suppose we have many features:

Feature 1
Feature 2
Feature 3
Feature 4
Feature 5
...

PCA can reduce them to fewer dimensions.

from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

iris = load_iris()

X = iris.data

# Standardize data
X_scaled = StandardScaler().fit_transform(X)

# Reduce 4 dimensions to 2
pca = PCA(n_components=2)

X_pca = pca.fit_transform(X_scaled)

print(X_pca.shape)

plt.scatter(
    X_pca[:, 0],
    X_pca[:, 1]
)

plt.xlabel("Principal Component 1")
plt.ylabel("Principal Component 2")

plt.title("PCA")

plt.show()
Example 8: PCA + K-Means

This is a very useful combination.

from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

iris = load_iris()

X = iris.data

# Scaling
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# PCA
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

# K-Means
model = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

clusters = model.fit_predict(X_pca)

# Visualization
plt.scatter(
    X_pca[:, 0],
    X_pca[:, 1],
    c=clusters
)

plt.xlabel("PCA Component 1")
plt.ylabel("PCA Component 2")
plt.title("PCA + K-Means")

plt.show()

This gives a nice workflow:

Raw Data
   ↓
Scaling
   ↓
PCA
   ↓
K-Means
   ↓
Clusters
